# Features Overview
- Real time data logging and monitoring without the need for a computer or aftermarket sensor installation - read and display data directly from the ECU and control modules.
- High resolution, touch screen display.
### Does it work on my car?
**Model year before 1993:** No. CANbus was not adopted into automotive standards prior to this year.\
**Model year 1994 to 2007:** Maybe! CANbus was not yet required but many manufacturers used it anyways. See how to check your car here (TODO: add link)
